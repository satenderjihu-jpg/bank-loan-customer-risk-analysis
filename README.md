# Bank Loan & Customer Risk Analysis

## Project Overview

This project analyzes loan applications, customer profiles, loan performance, and default risk using SQL.

## Objectives

- Analyze loan application patterns
- Understand customer profiles
- Analyze loan approval and rejection
- Identify loan types and customer segments
- Analyze default risk across cities
- Identify high-value customers by loan type

## Tools Used

- MySQL
- SQL
- GitHub

## Dataset

The dataset contains loan application and customer-related information including:

- Customer details
- Employment type
- Annual income
- Loan type
- Loan amount
- Interest rate
- Loan status
- Credit score
- Default status

## Analysis

The project contains 15 business questions covering:

- 10 Beginner-level SQL questions
- 3 Advanced SQL questions
- 2 Ultra-Advanced SQL questions

## Files

- `bank_loan_analytics_raw.csv` — Raw dataset
- `bank_loan_analysis.sql` — SQL analysis queries
